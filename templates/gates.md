# WDF Gates – Entscheidungsvorlage

| Gate | Prüffrage | Entscheidung durch |
|---|---|---|
| G1 | Vision, MVP, Requirements, Tech Stack und Risiken klar? | Mensch |
| G2 | Integrierter Build und Testumgebung nutzbar? | Mensch oder dokumentierter, vorab autorisierter Prozess |
| G3 | Akzeptanzkriterien getestet, Blocker behandelt, Risiken akzeptiert? | Mensch |
| G4 | Feedback gesichtet und nächste Iteration priorisiert? | Mensch |

## Eintrag pro Entscheidung
- Gate / Projekt / Feature / Version:
- Datum / Entscheider:
- Status: offen / freigegeben / zurückgestellt / abgelehnt
- Nachweise / offene Risiken:
- Folgeaktion:

Nicht aus einer Dateiexistenz oder CI-Erfolg automatisch eine Freigabe ableiten.
